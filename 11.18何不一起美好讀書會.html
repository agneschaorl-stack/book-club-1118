01 / Course Essence

課程核心要點：從概念理解到動手實作

本次讀書會聚焦於本機端 AI Agent 的實際操作。透過系統化的教材引導，讓同學們理解如何讓 AI 直接讀取電腦中的文字與影像檔案，協助完成日常資料整理與網頁製作。

Point 01

零程式基礎即可上手

免除繁複的語法記憶，學習以條理分明的文字敘述交代任務背景與需求，交由 AI Agent 自動建立 `index.html` 與專案架構。

Point 02

三大主流工具客觀評比

針對 Claude Code、ChatGPT/Codex 與 Google Antigravity，從「功能特性與優缺點」及「訂閱費用與周邊生態」兩大維度深入剖析。

Point 03

個人素材轉化為質感網頁

將預先準備的旅遊照片、閱讀筆記或生活紀錄放入專屬資料夾，透過多輪對話逐步微調版面細節，產出第一支個人網頁作品。

Point 04

版本控制與雲端硬碟串接

建立 GitHub 版本控制觀念以妥善保存修改歷程，並配合 Google 雲端硬碟同步圖片與文字素材，實現跨裝置管理與線上發布。

五大核心實作學習地圖

結合課堂手繪視覺指南與投影布幕上的《AI 實作教室》七大單元（學習路徑、安裝工具、工具比較、能力與額度、真正開始、指令小抄、佳作與發布），循序漸進完成實作流程。

課堂手繪學習地圖（點擊可放大檢視） 2026.11.18

行前準備與課前需求

  • • 零程式基礎即可參加：具備想法並願意動手嘗試，無須任何程式撰寫經驗。
  • • 自備筆記型電腦與充電器：攜帶個人 Windows 或 Mac 筆電至現場同步操作。
  • • 準備個人小主題與素材：預先準備文字與照片檔案，亦可使用課堂提供之範例練習。
1

安裝與設定本機 AI Agent

於個人筆電完成工具部署，並藉由課堂整理的兩張核心比較圖（能力優缺點比較、月費與生態系比較），選擇合適的主力工具。

Claude Code ChatGPT / Codex Google Antigravity
2

開始與切換任務前，確認工作資料夾位置

建立良好的專案管理習慣：每當開啟新作品或新對話時，先建立專屬資料夾並執行「工作資料夾確認指令」，確保素材與成品路徑清晰，避免沿用舊路徑或散落桌面。

└── 想要素材.txt └── 照片/ └── index.html
3

指導 AI 創建與修改網頁

練習交代任務指令，由 AI 讀取資料夾內的文字與照片素材建立網頁檔案，再依據預覽畫面逐步調整版面結構與視覺風格。

4

串接 GitHub 版本控制與雲端同步

將本機專案連結至 GitHub 進行版本控制，並安裝 Google 雲端硬碟同步照片與文字素材，便於日後持續維護與跨裝置存取。

5

作品發布與日常延伸應用

透過線上預覽與發布功能，將完成的靜態網頁轉化為可公開瀏覽的網址，靈活應用於各類生活紀錄與知識整理。

03 / Practical Applications

AI Agent 於日常生活中的延伸應用

掌握「資料夾結構管理」與「明確指令溝通」兩項基礎後，同學們即可將課堂所學延伸至多種日常情境：

影像與活動歸檔

旅遊相簿與聚會紀錄網頁

將旅途或聚會照片彙整於資料夾，由 AI 讀取影像時間與主題內容，自動編排為圖文並茂、支援燈箱檢視的典藏網頁。

知識管理與寫作

閱讀筆記與專題彙整

將平日記錄於純文字檔（`.txt`）的讀書心得或課程重點，交由 Agent 梳理脈絡、提煉摘要並製作成結構清晰的閱讀專頁。

數位資產整理

本機檔案與雲端同步管理

運用課堂傳授的「五步驟位置確認法」，請 Agent 協助檢視目錄結構、批次整理檔案命名，並同步備份至 Google 雲端與 GitHub。
